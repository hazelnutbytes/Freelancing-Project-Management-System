# Freelancing Project Management System

A simple Java Swing application for managing freelancers, clients, projects, proposals, and payments.

## Features

- Freelancer Management
- Client Management
- Project Management
- Proposal Management
- Freelancer Shortlisting
- Project Status Management
- Payment Management
- Project Search
- Freelancer Search
- Project Sorting by Budget and Deadline
- Project Report
- Input Validation and Exception Handling

## Java Concepts Used

- Classes and Objects
- Constructors
- Arrays
- ArrayList
- LinkedList
- HashMap
- TreeMap
- CRUD Operations
- Searching and Sorting
- Java Swing GUI
- Event Handling
- Exception Handling
- Data Validation

## How to Run

1. Make sure Java is installed.
2. Open the project folder in VS Code or any Java IDE.
3. Compile the program:

```bash
javac FreelancingSystem.java
